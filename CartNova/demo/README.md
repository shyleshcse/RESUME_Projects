# CartNova – Static Demo

Open `index.html` in a browser, or drag this folder to https://app.netlify.com/drop.

- Products come from the free DummyJSON API (internet needed).
- Cart, orders, wishlist and addresses are saved in the browser (localStorage).
- Demo logins: Customer `emilys` / `emilyspass`, Admin `admin` / `admin123`.
- This is a DEMO project: no real payments or deliveries.
